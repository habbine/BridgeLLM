# Contributing

The quickest way to help is to assess terms from the [term list](assessment/TERMS.md).

## Assess a term (no technical skills needed)

1. Open [`assessment/TERMS.md`](assessment/TERMS.md).
2. Click a term. A form opens with the term already filled in.
3. Choose a verdict, add comments and sources if you have them, and press **Submit new issue**.

You need a free GitHub account. Assess as many or as few terms as you like.

## Other ways to help

- **Missing term:** use the [Suggest a missing term](../../issues/new?template=add-term.yml) form.
- **Disagree with someone's assessment:** reply in that issue's comments.
- **Prefer a spreadsheet:** [`assessment/terms.csv`](assessment/terms.csv) lists every term. Send your notes in an issue, one comment per term.
- **Pull requests:** welcome for the existing glossary files. Keep one change per pull request.

## Good assessments

- Say what is wrong or missing, not only that something is.
- Cite the exact provision, paragraph or page where you can.
- Separate legal meaning from technical meaning when they differ.
